# Anime Discovery using the SparrowAnime
its a responsive web application that lets user(sparrows) search,discover and save fav anime using the jikan API a scarpper for MyAnimelist databse
it fetches the response in form of message which will be compard with the base url for the jikan incase of genre based or searching for the word

## you can view the live demo here
https://anime-api-lac-six.vercel.app/

### features that sparrowanime have
-search: enables you to search for an anime
-genre: filters the home tab with
-hometab: this when clicked fetches the top rated anime in jikan
-favtab: this contains the fav list of your fav anime once marked or checked the heart icon
-recentlyviewed; this gets the recentlyviewed after clicking the animelist card 
-modernized design with video: user friendliness
